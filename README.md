# Accordion Component

A responsive FAQ accordion component built with HTML, CSS, and JavaScript. Only one section stays expanded at a time to keep the layout organized and legible.

This project is a solution to the [roadmap.sh Accordion Project](https://roadmap.sh/projects/accordion).

## Live Demo

- **Live URL:** [https://frontend-basic-kappa.vercel.app/](https://frontend-basic-kappa.vercel.app/)

## Features

- **Single-Open Behavior:** Expanding any accordion section automatically closes any previously open section.
- **Smooth Animations:** Fluid height expansion and icon rotation transitions.
- **Accessible & Semantic:** Structured with semantic tags and keyboard navigation support.
- **Responsive Design:** Optimized for all screen sizes from mobile to desktop.

## Built With

- HTML5
- CSS3 (Flexbox, transitions)
- JavaScript (DOM manipulation)
